Fluxo principal

  • Splash → Entrar (sem sessão) ou Lista de Clientes (com sessão).
  • Entrar → Esqueci minha senha → Recuperar senha → Link enviado → Entrar.
  • Entrar → Lista de Clientes → toque no cliente → Ficha do Cliente.
  • Ficha → Fiado → Novo Fiado → (Passa do limite) → Ficha atualizada.
  • Ficha → Pagou → Registrar pagamento → Ficha atualizada.
  • Lista → Novo cliente → Cadastro de cliente → Ficha do novo cliente.

Convenções

  • Canvas 360 × 800 dp, retrato, tema claro.
  • Valores em reais gravados em centavos; datas no formato dd/mm.
  • Todos os dados são fictícios; o parceiro é simulado para fins acadêmicos.
  • Sem autocadastro: contas criadas apenas pelo proprietário.

Fiado Fácil · Design system: tokens, componentes e manual da marca no artefato “Fiado Fácil”.
