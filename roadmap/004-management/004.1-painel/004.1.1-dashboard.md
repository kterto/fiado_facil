# 004.1.1 — Dashboard: total receivable and overdue [mvp] [delivery]

## Brief
Add a dashboard (painel) available to every active user, reachable from the client list top bar. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting. There is no design file for this screen. Build it only from the existing design system (tokens, type scale, components and patterns in `docs/design/*.html` and the app theme), and add a visible note in the story's output summary that the screen **needs design validation** by the product owner.

- "Total a receber" = sum of positive saldos across active clients.
- "Em atraso" list using the domain overdue rule: name, saldo, days since last payment (or since the open balance started), tap opens the ficha; sorted by saldo descending.
- Works offline from cache; empty state when nobody is overdue.
