# 004.2.1 — Edit client, limit and deactivate [mvp] [delivery]

## Brief
Let any active user edit a client's nome, telefone, endereço and credit limit, and deactivate a client, from the ficha. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting. There is no design file for this screen. Build it only from the existing design system (tokens, type scale, components and patterns in `docs/design/*.html` and the app theme), and add a visible note in the story's output summary that the screen **needs design validation** by the product owner.

- Reuse the "Novo cliente" form layout and validation; changing the name updates `nome_busca`.
- "Desativar cliente" with a confirmation dialog; allowed even when saldo > 0 (the client is hidden from the list but its records stay). Clients are never deleted.
- Reactivating a deactivated client is an **open product decision** — do not build it.
