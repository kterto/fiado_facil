# 005.1.1 — End-to-end suite for critical flows [mvp] [delivery]

## Brief
Build an `integration_test` suite against the Firebase emulators covering the ten critical flows in `.orchestrator/PROJECT-CONTEXT.md`. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting.

- Seed script for the emulators: one dono, two atendentes (one inactive), a handful of clients with history.
- Include an offline scenario (network disabled → fiado, payment, cancel → reconnect → synced).
- One command runs the whole suite; document it in PROJECT-CONTEXT `## Test tooling`.
