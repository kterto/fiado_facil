# 001.2.1 — Domain entities and validation [mvp] [hardened]

## Brief
Implement the pure-Dart domain model and input validation, with no Flutter or Firebase imports in the domain layer. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting.

Entities (field names mirror the Firestore schema in `docs/foundation/ACTORS.md`):
- `Usuario`: uid, nome, email, papel (`dono` | `atendente`), ativo, criadoEm.
- `Cliente`: id, nome, nomeBusca, telefone (digits only), endereco?, limiteCreditoCentavos? (null = no limit), ativo, criadoEm.
- `Lancamento` (compra): id, clienteId, valorCentavos, descricao?, dataHora, registradoPor, acimaDoLimite, cancelado, canceladoPor?.
- `Pagamento`: id, clienteId, valorCentavos, dataHora, registradoPor, cancelado, canceladoPor?.

Validation (all money is `int` centavos, never `double`), with the exact pt-BR messages from the designs:
- nome required, trimmed, ≤ 80 → "Digite o nome do cliente."
- telefone 10 or 11 digits → "Telefone incompleto: digite o DDD e o número, com 10 ou 11 dígitos." Display mask `(81) 90000-0000` / `(81) 9000-0000`.
- endereco optional ≤ 120; limite optional, > 0 → "O limite precisa ser maior que zero, ou deixe em branco."
- valor > 0 and ≤ 9.999.999 centavos → "Digite um valor maior que zero."
- descricao optional ≤ 100.
- Any text containing `<` or `>` → "Use só letras, números e pontuação simples. Remova os símbolos < e >."

Also add data-layer mappers between entities and Firestore maps using the snake_case field names (`valor_centavos`, `registrado_por`, `acima_do_limite`, `cancelado_por`, `nome_busca`, `limite_credito_centavos`, `data_hora`, `criado_em`), with round-trip tests.

## Acceptance
- Unit tests cover every rule at its boundaries (79/80/81 chars, 9/10/11/12 digits, 0/1/9.999.999/10.000.000 centavos, 100/101 chars, `<`/`>` anywhere).
- Error strings match the design copy verbatim.
- The domain layer imports neither Flutter nor Firebase.
- Mapper round-trip tests pass for all four entities, including null optionals.
- Coverage of the domain layer ≥ 90%; format/analyze/test green.
