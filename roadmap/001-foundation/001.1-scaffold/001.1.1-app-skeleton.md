# 001.1.1 — App skeleton and design-system foundation [mvp] [delivery]

## Brief
Replace the Flutter template counter app with the Fiado Fácil app shell. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting.

- Create the layered structure under `lib/` (presentation, domain, data — pick concise folder names) and update the `## Layout` section of `.orchestrator/PROJECT-CONTEXT.md` with the folders you chose.
- Add `provider`, `intl` and `flutter_localizations`; the app is pt-BR only (locale `pt_BR`), title "Fiado Fácil", portrait, light theme only.
- Build the theme from the design tokens in `docs/design/*.html` (`:root` CSS block): colors (`--bg #f7f5f1`, `--surface #ffffff`, `--text-primary #1c1b1a`, `--text-secondary #4f4b45`, `--border #7a746b`, `--divider #e3dfd8`, `--primary #1e6b43`, `--primary-pressed #17573a`, `--primary-container #e6f2ea`, `--warning-container #fff3d6`, `--on-warning #6b4500`, `--error #b3261e`, `--error-container #fdecea`, `--info #1e4e8c`, `--info-container #e8f0fb`, `--disabled-bg #d9d5ce`), spacing 4–40, radii 8/12/16, sizes (touch 48, button 56, field 56, amount field 72, list item 64, top bar 64).
- Typography: **Atkinson Hyperlegible** 400/700 bundled as font assets (must work offline; OFL licence file included). Type scale from the design, except body text is **18** (design's 16 raised) and nothing renders below 16: balance 32/40 bold, amount input 28/36 bold, title 22/28 bold, label 18/24 bold, body 18/26, meta 16/22.
- Formatting helpers: integer centavos → `R$ 1.234,56` (and negative), digits-only input → centavos, dates `dd/mm/aaaa` and `dd/mm` in America/Recife (fixed UTC−03:00, no DST).
- Reusable widgets matching the design's component list: primary / secondary / text button (with optional disabled-reason line), TopBar, OfflineBanner, TextField with FieldError, MoneyField (`R$` prefix, right-aligned tabular value), Snackbar helper (4 s), ConfirmDialog (LimitAlert layout on surface background).
- A placeholder home screen; update `test/widget_test.dart` accordingly.

## Acceptance
- `lib/main.dart` no longer contains the counter template; the app launches to a pt-BR placeholder screen using Atkinson Hyperlegible from bundled assets.
- Unit tests: `0 → "R$ 0,00"`, `123456 → "R$ 1.234,56"`, `9999999 → "R$ 99.999,99"`, `-2210 → "-R$ 22,10"` (or the chosen negative form, documented), date formatting in America/Recife.
- Widget tests render each reusable widget; touch targets ≥ 48dp and primary buttons 56dp high.
- Theme colors and sizes equal the design tokens; base body text is 18.
- `dart format --output=none --set-exit-if-changed lib test`, `flutter analyze` and `flutter test` pass.
