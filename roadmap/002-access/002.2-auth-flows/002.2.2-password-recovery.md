# 002.2.2 — Password recovery (A3, A4) [mvp] [delivery]

## Brief
Build "Recuperar senha" (`docs/design/03-recuperar-senha.html`) and "Link enviado" (`docs/design/04-link-enviado.html`) using Firebase Auth password-reset email. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting.

- Email carried over from Entrar; same email validation messages as login.
- Always continue to A4 whether or not the account exists ("Se existir uma conta com {email}, …").
- Resend with snackbar "Link reenviado." and a 60-second countdown ("Você pode reenviar em 60 segundos."); offline messages exactly as the designs.
- Back navigation per the design flow.

Commit with trailer: Roadmap-Story: 002.2.2

## Acceptance
- Widget tests for all design states of A3 and A4, including the countdown and offline states.
- Against the emulator, requesting a reset produces a reset email in the Auth emulator for an existing account and shows A4 for an unknown one.
- format/analyze/test green.
