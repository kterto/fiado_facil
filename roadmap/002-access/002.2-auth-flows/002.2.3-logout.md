# 002.2.3 — Logout with unsent-records warning [mvp] [delivery]

## Brief
Add the top bar user name and "Sair" action and the logout modals from `docs/design/05-lista-clientes.html`. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting.

- Count local writes not yet sent to the server (Firestore pending writes across `clientes`, `lancamentos`, `pagamentos`).
- Pending > 0: modal "Sair do aplicativo?" / "Há N registros que ainda não foram enviados. Conecte o celular à internet antes de sair, ou eles serão perdidos." with "Ficar no app" and "Sair mesmo assim".
- Pending = 0: modal "Você vai precisar do e-mail e da senha para entrar de novo. Os dados ficam salvos com segurança." with "Sair" / "Voltar".
- Sair signs out and clears the local Firestore cache (terminate + clearPersistence, then re-initialize), returning to Entrar.
- Put the top bar on the current home placeholder; the client list story will reuse it.
