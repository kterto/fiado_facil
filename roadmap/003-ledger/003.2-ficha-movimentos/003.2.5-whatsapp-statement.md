# 003.2.5 — Send statement via WhatsApp [mvp] [delivery]

## Brief
Make "Enviar extrato" on the ficha open the customer's WhatsApp chat with the statement text pre-filled. Read `.orchestrator/PROJECT-CONTEXT.md` (Invariants, Conventions, Commands) and `docs/foundation/INTENT.md` / `ACTORS.md` before starting.

- Build the text with the domain statement function.
- Show a preview (bottom sheet or screen) of the exact text with a "Enviar no WhatsApp" action. There is no design file for this screen. Build it only from the existing design system (tokens, type scale, components and patterns in `docs/design/*.html` and the app theme), and add a visible note in the story's output summary that the screen **needs design validation** by the product owner.
- Open `https://wa.me/55{telefone}?text={urlencoded}` with `url_launcher` (external app). The person still taps send in WhatsApp — no automation, no WhatsApp Business API.
- If WhatsApp cannot be opened, fall back to the Android share sheet (`share_plus`) with the same text and tell the user why.

Commit with trailer: Roadmap-Story: 003.2.5

## Acceptance
- Unit test: generated wa.me URL has the 55 prefix, digits-only phone and correctly encoded text (accents, line breaks, R$).
- Widget test: preview shows the exact statement; fallback path triggers the share sheet.
- Output summary notes the preview screen needs design validation.
- format/analyze/test green.
